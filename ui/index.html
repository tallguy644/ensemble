Ensemble

Every model answers, reads the others' answers and revises, then one merges the best into a final answer. Good for writing, research and decisions.

One model plans, another builds, a third reviews, and fixes loop until it's approved. Work lands on a new git branch in your project.

Build needs git (free), which isn't installed.
